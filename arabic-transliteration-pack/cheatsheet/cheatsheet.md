# Arabic Transliteration Cheat Sheet

Print this and keep it next to your keyboard.

```
╔══════════════════════════════════════════════════════════════╗
║          ARABIC TRANSLITERATION — QUICK REFERENCE            ║
║          Right Alt (RAlt) + Key = Special Character          ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  LONG VOWELS (Macrons)                                       ║
║  ──────────────────────                                      ║
║  RAlt + a = ā    RAlt + i = ī    RAlt + u = ū               ║
║  + Shift  = Ā    + Shift  = Ī    + Shift  = Ū               ║
║                                                              ║
║  DOT BELOW                                                   ║
║  ─────────                                                   ║
║  RAlt + h = ḥ    RAlt + s = ṣ    RAlt + t = ṭ               ║
║  RAlt + d = ḍ    RAlt + z = ẓ                                ║
║  + Shift for UPPERCASE: Ḥ Ṣ Ṭ Ḍ Ẓ                          ║
║                                                              ║
║  SPECIAL CONSONANTS                                          ║
║  ──────────────────                                          ║
║  RAlt + c = š  (shin)     RAlt + g = ġ  (ghayn)             ║
║  RAlt + x = ḫ  (kha)                                        ║
║  + Shift for UPPERCASE: Š Ġ Ḫ                               ║
║                                                              ║
║  LINE BELOW                                                  ║
║  ──────────                                                  ║
║  RAlt + v = ṯ  (tha)      RAlt + e = ḏ  (dhal)              ║
║  + Shift for UPPERCASE: Ṯ Ḏ                                 ║
║                                                              ║
║  AYN & HAMZA                                                 ║
║  ───────────                                                 ║
║  RAlt + [ = ʿ  (ayn)      RAlt + ] = ʾ  (hamza)             ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║  EXAMPLES                                                    ║
║  kitāb = kit[RAlt+a]b     ʿilm = [RAlt+[]ilm                ║
║  al-ḥakīm = al-[RAlt+h]ak[RAlt+i]m                          ║
║  Šams al-Dīn = [RAlt+Shift+c]ams al-D[RAlt+i]n              ║
╚══════════════════════════════════════════════════════════════╝
```
